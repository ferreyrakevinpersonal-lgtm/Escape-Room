# Escape Room Terminal

¡Bienvenido al Escape Room! Un juego interactivo basado en una terminal desarrollado en Visual Studio Code.

# Descripción

Este proyecto es un juego interactivo donde los jugadores deben resolver acertijos y usar comandos de terminal para lograr escapar.

Puedes jugarlo directamente en tu navegador aquí:
**[Haz clic aquí para jugar](https://TU-USUARIO.github.io/escape-room/)**

# Comandos del juego

Algunos de los comandos disponibles dentro de la terminal:

* `/help` - Muestra la lista de comandos disponibles.
* `/cls` - limpia la pantalla de la terminal.
